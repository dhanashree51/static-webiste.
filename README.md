# 🍽️ Static Restaurant Website

## 📌 Project Overview
This project is a static restaurant website designed to showcase a restaurant's food menu, services, and atmosphere through an attractive and user-friendly interface. It provides visitors with information about the restaurant, its dishes, and contact details.

## 🎯 Features
- 🏠 **Home Page:** An attractive landing page introducing the restaurant.
- 🍕 **Food Menu:** Displays available food items and their prices.
- 🖼️ **Food Gallery:** Showcases images of delicious dishes.
- 👨‍🍳 **About Us:** Provides information about the restaurant.
- 📞 **Contact Section:** Displays restaurant contact information.
- 📱 **Responsive Design:** Designed to work across different screen sizes, if implemented.

## 🛠️ Technologies Used
- **HTML5** – Structures the website content.
- **CSS3** – Styles the website and creates its layout.
- **JavaScript** – Adds interactive features, if implemented.

## 🚀 How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/static-restaurant-website.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

No backend server or database is required for this static website.
